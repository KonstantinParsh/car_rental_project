- Работать только через Python-скрипты: создание БД, создание таблиц и проверка структуры;

## Шаг 2. Подготовка окружения

Проект инициализирован как устанавливаемый Python-пакет с базовыми конфигурационными файлами для контроля версий.

### 1. Метаданные и сборка (pyproject.toml)

Создан файл `pyproject.toml` для декларативного управления проектом. Поскольку библиотека `sqlite3` является встроенной в стандартный дистрибутив Python, секция зависимостей `dependencies` оставлена пустой. Настройка `[build-system]` конфигурационного файла позволяет выполнять установку пакета в редактируемом режиме через команду:

```bash
pip install -e .
```

### 2. Контроль версий (.gitignore)

Настроен файл `.gitignore` для предотвращения попадания в общий репозиторий временных файлов, кэша компилятора Python (`__pycache__/`), виртуального окружения (`.venv/`) и локальных артефактов базы данных (`*.db`, `*.sqlite`, `*.sqlite3`).

### 3. Сохранение структуры данных (.gitkeep)

Так как система Git по умолчанию отслеживает только файлы и игнорирует пустые папки, внутри директории `data/` был создан пустой файл-заглушка `.gitkeep`.

- В файле `.gitignore` папка с данными зафиксирована следующим образом:

```text
.venv/
__pycache__/
data/*.db
data/*.sqlite
data/*.sqlite3
*.egg-info/
logs/*.log
```

## Шаг 3. Определение предметной области

- **Родительская таблица:** `cars` (Автомобили)
- **Дочерняя таблица:** `clients` (Клиенты)
- **Поле-связка в дочерней:** `car_id` REFERENCES `cars`(`id`)

## Шаг 4. Проектирование структуры таблиц

### Родительская таблица cars:

| Имя поля   | Тип     | Ограничения               | Назначение                            |
| :--------- | :------ | :------------------------ | :------------------------------------ |
| id         | INTEGER | PRIMARY KEY AUTOINCREMENT | Уникальный номер                      |
| brand      | TEXT    | NOT NULL                  | Марка автомобиля                      |
| model      | TEXT    | NOT NULL                  | Модель автомобиля                     |
| reg_number | TEXT    | NOT NULL UNIQUE           | Государственный регистрационный номер |

### Дочерняя таблица clients:

| Имя поля       | Тип     | Ограничения               | Назначение                        |
| :------------- | :------ | :------------------------ | :-------------------------------- |
| id             | INTEGER | PRIMARY KEY AUTOINCREMENT | Уникальный номер                  |
| first_name     | TEXT    | NOT NULL                  | Имя клиента                       |
| last_name      | TEXT    | NOT NULL                  | Фамилия клиента                   |
| patronymic     | TEXT    |                           | Отчество клиента                  |
| license_number | TEXT    | NOT NULL                  | Номер водительского удостоверения |
| phone          | TEXT    | NOT NULL                  | Номер телефона                    |
| car_id         | INTEGER | REFERENCES cars(id)       | Ссылка на родителя (автомобиль)   |
| rental_date    | TEXT    | NOT NULL                  | Дата начала проката               |

## Как запустить скрипт?

- Откройте `powershell`;
- Перейдите в корень проекта;
- Создайте директорию `.venv`:

```bash
python -m venv .venv
```

- Активируйте ее:

```bash
.venv\Scripts\Activate.ps1
```

- Установите проект:

```bash
pip install -e .
```

- Запускайте скрипты!!!
